## 原理、迁移与取舍

- 教材直接依据：驱动附着限制、轴载转移、左右纵向力差的横摆作用、制动过程分段、刚性侧翻边界。
- 条件整理：轴载除以总重的比例形式；游戏统一单位下的制动包络。公式假设逐条写明，不迁入公路轮胎经验系数、发动机曲线或真实制动延迟。
- 项目迁移：使用现有 PoweredWheel 左右独立动作作为替代转向候选；不等价于教材证明了四轮刚性差速运动学。
- 单独标记的推导：自由货物技能借用接触力约束与边缘力矩平衡，另外声明二维各向同性摩擦、水平矩形支承和均匀加速度假设。不是声称原书讲解了本项目货物或给出了游戏参数。
- 暂不提炼：变速器挡位、油耗优化、ABS/ESP、转向铰链和悬架调参。当前工具没有这些完整执行能力；本批次也未开展相关参数校准。
- 不输出完整车辆、按键固定时长宏或 BSG；不从 Support 成绩推断 Transport 的物理收益。
