## 迁移边界

- 教材直接依据：质量加权中心、合力与主矩、反作用推进、同向同时推力组合、外力与质心运动、力矩对角动量的积累。
- 本项目条件推导：竖直等效质量区间、短时角冲量、中心/对置/十字模块目标。这些不是教材为Besiege给出的参数或最优结构。
- 游戏专属部分：火把热球半径0.3、水炮冷/蒸汽标称反冲1.6/13.76、无附着面、固定按键、可用积木和Brace端点限制，全部分别引用仓库代码。
- 暂不提炼：喷管喉径/膨胀比、比冲优化、推进剂选择、变质量速度增量、分级抛弃、气动尾翼、万向喷管、自动节流与姿态控制。缺少相应游戏参数或原有工具执行能力；木板外形不能替代已经校准的气动面。
- 不宣称几何中心是真实质心、包围盒就是热接触表面、零主矩就是稳定，或持续按键就一定全炮同时进入蒸汽态。

## 当前环境与评价差异

| 项目 | 核对结果及对技能的影响 |
| --- | --- |
| Soft | 一个子结构，构造单向推进发动机；任务文字按竖直位移描述推进评价，实际布尔通过为配置推力代理除以配置质量大于1。不能将其称为实测最大竖直推力。 |
| Medium | 一个子结构，要求从地面升空并尽量竖直上升；不能借技能额外拆分独立任务。 |
| Hard | 两个子结构，发动机与底盘用Brace形成对称火箭；计划明确发动机复用实例，最终总装重新核对质量、推力、接口与热区。 |
| 动力块 | 现有Water Cannon和Torch均允许使用且无附着面。没有已暴露的专用火箭发动机、尾翼或万向喷管；Ballast禁止由Agent添加。 |
| 控制 | Lift直接进入原适配器，无Controller优化回路。所有水炮映射Alpha1，2秒开始，Soft保持10秒，其余30秒；总观测窗口分别10/30秒。 |
| 放置 | Windows执行路径使用 `set_ground=True` 贴近地面；构建时坐标和热区布局仍要与最终场景位置区分，不把地面支撑视为固定端。 |
| 跟踪 | 不跟踪Starting Block；Soft跟踪其余所有块。Medium/Hard非起始块超过4个时随机选4个，没有固定抽样种子。不能保证每个水炮都有热状态记录。 |
| 推力代理 | `burning=true`曾出现的水炮计为active，按13.76计算；其余按1.6。代理忽略喷流方向和热状态持续性，未被跟踪的水炮也会落入inactive。 |
| Medium/Hard通过 | 当前检查被跟踪块 `max_height>30` 且 `elevation_change>5`。后者为 `(7,12]` 秒内最大高度减去 `(2,7]` 秒内最大高度，非最终高度减初始高度。 |
| 轨迹质量 | 理想参考竖直线的目标向量用 `[0,0,1700]`，1700不是任务要求达到的高度。名为质心轨迹的辅助函数实际取被跟踪位置的算术均值。 |
| 完整性与稳定 | 高度、速度可能来自某个被跟踪的碎块；通过条件不直接证明整机保持连接、无翻转或全程竖直。保留任务目标，不能利用指标简化来替代目标完成。 |
| 方向审核 | 水炮和火把 `spin=false`，不会自动触发独立Refine；Draft/Build就应通过当前recipe中的朝向操作完成核对。 |

这些差异仅记录；本次没有修订分析器、任务定义、抽样、控制、加热参数或任何历史实验结果。
